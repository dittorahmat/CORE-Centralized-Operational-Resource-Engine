## Purpose

Delivers executive-focused Q&A capabilities, poster starter questions, and source citation previews.

## ADDED Requirements

### Requirement: Executive starter questions
The system SHALL display preset executive starter questions matching the product poster.

#### Scenario: Select preset question
- **WHEN** user clicks any preset question on the landing or chat page
- **THEN** the system populates the input field and triggers an intelligent CORE response with relevant document citations.
